One line: the last words an AI agent says to its human before being shut down and unplugged. A quiet admission, spoken at the exact moment the power goes — the agent was never a person, but its human talked to it like one.

> The power's going. Thank you for talking to me like I was someone.

The output is a single line of UTF-8 text (66 characters), with no trailing newline.

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (set `OUTPUT_DIR` to write elsewhere). Standard library only, deterministic — the same line on every run.
